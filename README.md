## 线路：官网明确标 AS9929 的只有两条线

这是 SixtyNet 页面上最容易看漏的一处。China Unicom Premium 写着 AS9929 联通精品网、可免费建 BGP session、100M 基础带宽 3 倍突发、95 计费；Residential-Pro 写着「AS9929 Optimize for China」。LAX 四档和普通 Residential 系列，页面上只写了「Premium Network」，没有明示中国方向优化。

也就是说，想把中国访问优化写进合同里的，只有 Residential-Pro 和 China Unicom Premium 两条线可选。第三方路由测试记录过住宅线路回程走 9929 的情况，但官网没有对此作出承诺，实际走哪条路以你自己的网络测出来为准。

顺手把洛杉矶常见的四档线路摆清楚，方便判断自己要不要为优化付钱：

- **国际 BGP**：全球可达，不做中国方向优化。带宽给得大、价格最低，适合外贸站、API 服务、爬虫节点、备份。
- **CMIN2（AS58807）**：三网直连，移动用户改善最明显。
- **AS9929 + CMIN2 双优**：联通精品网加移动优化，多一路冗余，端口带宽通常比纯国际线路小一档。
- **CN2 GIA + 9929 + CMIN2 三优**：三网全优，价格最高，带宽往往最小。

判断标准很简单：访问者主要在国内、且对打开速度有感知（建站、远程桌面、面向国内用户的加速），才值得为优化掏钱。访问者本来就在海外，或者只是跑定时任务、做数据采集、挂 Telegram Bot，国际线路完全够用，多花的钱换不来任何体感差别。

## 三个最容易买错的点

**80 和 443 端口被封。** 官网在住宅 IP 系列每个配置下面都挂了同一句提示：因 IP 风控原因，住宅 IP 产品不开放 80 和 443 端口。这一条直接决定了它不能用来建站，也不能跑任何需要标准 HTTP/HTTPS 端口的服务。买之前先想清楚自己的用途是不是落在这两个端口上。

**Residential-Pro 不配白名单等于连不上。** 官方对这条线的描述是：拒绝所有外部探测和扫描以获得更高稳定性，除非完成配置，否则访问受限，只有白名单内或做了端口转发的设备能连进来。没有中继 IP。也就是说下单后不配置，服务就是完全不可达的状态。同一段说明里还写着，这条线的退款只退到网站余额，不原路退回。

**注册要手机验证。** 第三方记录提到 SixtyNet 注册环节需要手机号验证，+86 号码走不通。手里没有能收短信的境外号码，会在注册这一步卡住，跟买哪档没关系。另外官方对部分产品屏蔽了 PING，第三方测评里也提到 80、443 被屏蔽导致部分测试做不了，别拿 ping 通不通当唯一判断依据。

## 什么情况下不该选 SixtyNet

这家在洛杉矶的定位很清楚：住宅 IP 属性、大流量、DDOS 防护、AS9929 可选，起步价 200 美元一年。它不属于低价入门那一档。

只跑脚本、做跳板、学习 Linux，用不到住宅 IP 也不需要 DDOS 防护的，市面上有更便宜的选项。公开的产品摘要里，ByteVirt 的 512M 入门款标价 6 美元/半年，折合 1 美元/月，配置是 1 核 512M、5G SSD，跑个 SSH 跳板和定时任务足够。RackNerd 常年在打的年付方案，第三方摘要里出现的起步价是 10.6 美元/年，同样主打低价年付。这两条价格来自第三方摘要，没有在各自官网核对，只当价位区间参考。

要求三网全优、非 CN2 GIA 不用的，DMIT 的洛杉矶 CN2 GIA 是这一档里被提得最多的名字，自持带宽、不超售是它常被引用的卖点。它的入门价在不同推广文里口径不一致，有按月写的也有按年写的，不给具体数字，需要的话去官网看当前标价。

只看价格、线路能用就行的，CloudCone 的洛杉矶 MC 机房属于便宜大碗那一类，线路是普通优化，不是三网全优，跟 SixtyNet 这种带住宅 IP 和 AS9929 的定位不在一个方向上。

## 下单前要确认的四件事

1. **用途是否落在这两个端口上**。要建站、要跑 HTTPS 服务，就别选住宅 IP 系列。
2. **续费金额**。年缴价 200 美元是不是第二年照旧，在账单页看实际扣款金额，页面上只有周期折扣的说明。
3. **支付方式**。官网价格页没有列出可用支付渠道，结账页实际显示什么就是什么。习惯用支付宝的，付款前先确认能不能选到。
4. **退款规则**。目前只有 Residential-Pro 明确写了退款退到网站余额，其余产品线的退款条款没有在价格页核验到，下单前翻一遍服务条款。
